# Auto3D 0.37.4 / Packaging 1.7.3

Saved RSC crease meshes from before Packaging 1.7.2 have edge/inner/closed GPU material slots but no outer-liner slot. Replacing their display geometry with the new liner-based bridge previously fell back from the outer-liner definition index to GPU slot zero, rendering the bridge as exposed corrugated edge. The presenter now resolves missing facing slots from the same object’s panel materials and appends the actual renderer material without altering the saved engine mesh or material records. Existing slots remain in order, and repeat updates/cache hits do not duplicate slots. Custom liner artwork is reused directly rather than replaced.

Cloudflare canonical deployment 21804de8-51be-463b-bb7f-e9b87b6a9d43 contains merged PR #41 (commit d5d69adc1d7a540b85ed78cfd2c17856d1c8a069). This confirms deployment of the prior implementation; the material compatibility defect is independently reproduced by unit tests. A real closed-RSC archive capture subsequently reproduced the dark top band even after the binding fix. The top-fold triangles all had geometric winding opposite to their supplied outward normals (128 reversed triangles per top bridge); glue-tab caps also had mixed winding. Two-sided rendering inverted the lighting normals. Crease triangles now align winding with their outward normals at every pose, and fold playback updates UV buffers alongside position/normal buffers so corrected vertex order stays registered. The previous visual review used an open HSC and missed the closed-RSC top folds.

New versus saved closed RSC rendering and main-viewer archive opening are checked. Original CAD coordinates, dimensions, texture data and saved Library files are unchanged. Existing archived texture images remain preserved; this patch corrects the display binding rather than silently upgrading artwork. No database or server change.
