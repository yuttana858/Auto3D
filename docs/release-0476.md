# Auto3D 0.47.6 / Packaging 1.10.3

Focus frames the combined visible bounds of the selected objects, including grouped objects. Right-drag orbits around and looks toward the center of that selection. The shared `view.focus` command retains multi-selection unless an explicit object is supplied. Hidden objects do not affect framing. Fit All remains separate.

The session bar no longer shows copy and paste buttons; Ctrl/Cmd+C and Ctrl/Cmd+V remain available. Sharing checks the saved archive size and asks the user to proceed explicitly with the original when it exceeds 5 MiB. Alternative mobile/desktop share archives are not implemented; see `docs/share-optimization-review.md`.
