# Auto3D 0.54.1 / Packaging 1.10.5 / Primary Products 0.5.0

The packaging CAD editor adds an inside/outside face and measurement view, a movable preview of the main 3D scene, board flute direction, multi-selection line assignment, independent perforation cut and gap settings, and physical-scale EPS export. SVG and DXF distinguish cut, score and perforation layers; EPS uses color-coded process groups, not editable CAD layers.

Artwork import, independent artwork layers, automated arbitrary folding-rig reconstruction and automatic application of edited CAD paths remain unimplemented. The preview displays the current scene and therefore reflects committed model changes. Converter-calibrated allowances are needed for reliable inside/outside dimensions; the view marks missing factors.
