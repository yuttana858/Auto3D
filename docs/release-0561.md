# Auto3D 0.56.1 — browser regression suite repaired

Packaging 1.10.6; Primary Products remains 0.7.0. PR #94, based on main after merged PRs #92, #93 and #91 (0.56.0 / Packaging 1.10.5 / Primary Products 0.7.0). Not deployed.

All 23 browser tests that were outside CI with stale expectations now pass and are part of the CI `browser` job (`test/browser/ci-suite.txt`, 64 tests). They failed because the app had intentionally changed: the board caliper limit is 15 mm, the Packaging designer starts on the select tool, FEFCO style cards generate directly and asynchronously, new boxes default to the inside dimension basis (which needs converter allowance factors outside FEFCO 0201), selected-box dimensions moved to the selected column, Fold/Unfold is one state-aware control, Details, Lighting and Session sections start collapsed, "Apply scale" was replaced by live fields, array reveal and fold playback make the viewer busy, and Auto pixel ratio briefly lowers after camera updates. Tests read the app and module versions from package metadata instead of hard-coded numbers. No test was skipped or loosened to pass; assertions were updated to the documented behavior, and several were strengthened (for example, engineering-linked inside/outside dimensions are checked through `packaging.dimensions.inspect` and `packaging.measurements.inspect`).

Product fix (Packaging 1.10.6): the standalone Packaging preview failed at the end of every animated fold or unfold with "Cannot read properties of undefined (reading 'role')". The fold rig carries only liner and edge materials, so restoring inner and closed materials wrote `undefined` into the material list. The preview now falls back to the original box's materials. The Auto3D host path was not affected.

The full serial run also exposed three timing races, now fixed in the tests: `accounts` counted the administration link before the dialog finished its account refresh and did not mock the user list the dialog now loads; `board-panel-visibility` (already in CI) clicked the board-surface toggle while the previous rebuild was still busy, which Packaging 1.10.4 deliberately rejects, so it now retries until the change is accepted; and `packaging-fold-dimensions` waited without a limit for the narrow `open box` stage (progress 0.68–0.76), which a slow frame can skip, so it now pauses at the first sample in or after that stage.

Because software-GPU tests run two to three times slower on hosted runners, the CI `browser` job is split into three parallel shards, each test may take up to 600 s, and the slow Packaging tests (`packaging-presets`, `packaging-fold-dimensions`) wait up to 120 s for each step instead of 30 s. Assertions are unchanged. CI also starts the standalone Packaging preview (port 8082) for `packaging-module`, and waits for it before the run. `ai-extended` (timing-sensitive) and `mcp-access` (covered by the MCP workflow) stay outside the browser job.

UX fixes:

- **0202 overlap is no longer replaced silently.** `FefcoPreset` takes the fields the caller explicitly requested. An overlap carried over from another style still gets a fitting default when switching to 0202, but an overlap the user typed in the visible field, or passed to `packaging.fefco.preset`, is rejected with "0202 overlap must be greater than zero and less than the width." and nothing is generated. The hidden overlap field is not treated as a request.
- **Engineering-linked dimension edits report success.** `UpdateDimensions` sets "Updated box dimensions · <basis>" (with tolerance when changed), and every successful `UpdateEngineering` sets "Updated CAD measurements.", so an earlier "Enter a converter allowance factor…" error no longer remains after a later edit succeeds.

After merging PR #92, the SVG/EPS/DXF export buttons wrap onto two rows; the browser tests now check their reading order instead of SVG and DXF sharing a row.

Validation: 792 app/module tests, 64 MCP tests and application lint pass. The full 64-test browser suite passed serially before the PR #92 merge and in three CI shards; after the merge and UX fixes, fefco, packaging-fold-dimensions, packaging-presets, packaging-cleanup, packaging-thumbnail-generation, packaging-module, packaging-measurements and cad-apply pass locally.
