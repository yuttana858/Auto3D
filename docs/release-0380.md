# Auto3D 0.38.0 / Packaging 1.8.0

CAD now has a default selection arrow, point-to-point pen, Ctrl/Cmd additive path selection, a cut/crease selector, and crease/perforation settings. A 12px invisible continuous hit area makes dashed lines selectable between dashes. Bulk line assignment is one Undo step. New creases can carry standard/reverse crease, perforation, or crease-perforation metadata; perforation cut and tie lengths are canonical mm. Settings are validated, saved in profiles/archives and exported in named SVG/DXF layers. SVG includes cut/tie attributes and physical dash lengths; DXF retains continuous centerlines plus cut/tie comments. These exports are specifications, not production-ready converter tooling or simulated tearing.

**Apply to 3D** replaces the linked packaging object instead of adding a duplicate, keeping identity, transforms, materials, visibility, shadows, timeline keyframes and custom user data. Generation completes before replacement; render failures restore the original. Undo restores the previous object and leaves the edited CAD draft available; Redo reapplies it. Dimensions/materials retain their existing live rebuild when the active CAD matches the selected model.

Auto mode preserves the generated fold state when panel geometry still matches the supported FEFCO rig. Manufacturing process metadata does not change the rig coordinates. Arbitrary path edits cannot yet infer a new hinge graph: Apply refuses to leave a stale folded solid and requires the explicit **Flat board** choice. Flat Apply generates exact cut contours, holes and caliper with crease metadata, clears incompatible generated folding metadata, and preserves object identity. Open cut contours still require closing/removing before extrusion. A new fold rig for arbitrary dielines remains future work. CAD coordinates remain authoritative; display rounding and board textures do not alter them.

Shared agent commands: `packaging.apply`, `packaging.tool`, `packaging.paths.assign`, `packaging.crease.open`, `packaging.crease.configure`; `packaging.path.select` accepts `additive`. UI and commands share methods. `packaging.crease.open` is interactive and does not apply changes. The command catalog is regenerated.

The upload format/material hint and default “No embedded animation” help text requested for removal are gone. Real embedded-animation errors remain visible. The login password eye now has a dark icon against the light input and a keyboard focus ring. Forgot Password now explains administrator-assisted reset without requesting a non-deliverable email. The pending-delivery notice and startup saved-session service-unavailable banner are removed. Explicit sign-in failures still show actionable errors. Existing approved-account email recovery endpoints and captured-link reset remain for future activation; their rate limits, eligibility checks and session revocation remain in place.

Production password-recovery email delivery is not activated by this release. Supabase's default mail only serves project team addresses. The user chose existing Account admin → Reset password because no sender domain is available; no SMTP activation is required for this release. See [temporary-auth.md](temporary-auth.md). No live recovery email has been sent during verification.

Validation: 652 passing in the serial full unit/module suite, plus five final CAD Apply integration tests after the session-change safeguard. CAD browser checks cover arrow/pen, actual Ctrl-click hit areas, process settings, folded Apply, guarded custom folds and explicit flat Apply. Desktop/mobile login checks cover eye contrast, administrator guidance, quiet startup failure and captured recovery links. Lint, website, standalone Packaging and Pages builds pass. Earlier concurrent runs hit existing cold-texture timing limits; no existing test timeout was increased.
