# Auto3D 0.49.4 / Packaging 1.10.3 / Primary Products 0.3.0 — plugin authorization

The plugin approval page uses the signed-in Auto3D account without asking for a registration name or harness. A connection still requires explicit OAuth approval, retains account-scoping and individual revocation, and can select or pair a live window separately. Existing grants remain valid. See [MCP pilot](mcp-pilot.md).

The change has not been verified with a production client or deployed.
