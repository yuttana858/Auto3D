# Auto3D 0.39.0 / Packaging 1.9.0

Packaging's right panel now says **Box Dimensions**, with W × L × H in one row. Both generation and selected-box rows replace the direct caliper input with a Board selector grouped into E, B, C, EB and BC flutes. The selector uses the account catalog's exact millimeter caliper and paper/flute specification. Generation entries are CAD score-to-score spans; the selected box's Inside/Outside selector shows its compensated engineering dimensions. Per-design allowance factors remain separate from reusable board composition.

The gear beside Board opens a native module-owned **Board database CSV** editor. It supports opening/downloading a CSV file, direct editing and explicit **Save database**. All columns, flute names, uniqueness, paper/caliper relationships, numeric bounds and booleans are validated before writes. Records persist per account, with a revision check to reject overwriting a newer edit from another session. No account data is written merely by opening the editor. Saving a catalog can stage new specifications for subsequent generation without changing an existing model. A thicker board may be staged before increasing box dimensions; geometric constraints are validated on generation/application, not by incorrectly reporting a completed database save as failed.

A generated or explicitly updated box retains its own full material snapshot in the profile/archive. Selecting a new board for an existing linked box rebuilds exact CAD and geometry with identity, material edits, transforms and Undo retained. W/L/H edits on engineering-linked boxes use the Measurement layer's existing allowance math, preserving manual/parametric modes and recording one history step for a combined dimension edit. Catalog changes do not retroactively rewrite saved Library files. Maximum catalog: 32 records and 64 KiB requests/CSV; units are mm and g/m².

Initial catalog values reuse the app's existing **nominal** calipers: E 1.5, B 3, C 4, EB 4.5, BC 7 mm. They are editable starting points, not certified supplier grades. Nominal flute pitch and paper proportions are visualization defaults; actual supplier measurements should replace them. EB/BC caliper is supported for engineering compensation, while the existing medium rendering remains an approximate representative section rather than a full double-wall reconstruction.

Right-button dragging now orbits around the selected visible object's world-space bounds center. Eye and viewing target rotate together about that pivot, retaining framing and zoom without a snap. The pivot initializes only after the drag threshold, so a short right click still opens the context menu. Space+left pan, middle pan and pinch speeds remain unchanged. Hide, Delete, Library, Save, Export and Add/import actions are removed from the vertical tool strip; their existing menus, header controls, shortcuts and commands remain available.

All in-app native/legacy/context/color popups and rendered-image windows use the shared **+3px** typography layer. It adds to authored/computed text sizes without compounding inheritance, handles late content, and restores styles when a popup is removed. SVG/CAD annotations are excluded. The array dialog remains scrollable on small screens.

Shared commands: `camera.orbit.focus_selected`, `packaging.boards.inspect`, `.select`, `.open`, `.export`, `.save_csv`. The command catalog is regenerated. The CSV editor opens interactively; only explicit Save or the save command writes account records. Revision can be null on the first save.

Database prerequisite: migration `20261027185638_account_board_catalog` is applied to production. It adds one nullable JSONB field to the existing account-preferences table with a shape check, keeps RLS enabled and adds no browser grants. Existing preferences/folders and material snapshots are untouched. Verified metadata reports the column and constraint present, RLS true and zero anon/authenticated table grants. Security advisor results are unchanged. No production board catalogs were populated during development; the UI/API remain subject to PR deployment.

Validation: 667 unit/module tests pass. Desktop/mobile board browser checks pass for W/L/H layout, flute groups, precise caliper, CSV save/revision/reload, unchanged existing material snapshots, selected-board Undo and engineering dimension edits. Selected-orbit/tool-strip/array-font browser checks pass, including dynamic text and mobile. Separate legacy/render-window typography checks pass without compounding fonts or changing SVG annotations. Lint, website, independent Packaging and Pages builds pass. Database metadata and unchanged security advisors verified. An initial full run found an out-of-date command catalog; regeneration and the final full run pass.
