# Messenger recovery candidate

Auto3D 0.70.2 / Packaging 1.10.7 / Primary Products 0.15.0 / Molded Pulp 0.1.0. Restores the movable Messenger window from PR #119 and connects the AI tab to the existing session-only command-bar agent channel. Agent replies appear in the window and may be spoken when enabled. Account changes clear the command-bar log. Direct and group messaging, persistent history, and the requested layered defenses against malicious message instructions are not implemented. This is a draft candidate, not a complete Messenger release.
