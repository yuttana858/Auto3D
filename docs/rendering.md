# Rendering, ambient lighting and live model edits

Lighting includes an additional ambient fill with intensity (0–3×) and color. Zero preserves the existing default/HDRI lighting. Fill adds diffuse light and uniform specular radiance for metallic/clearcoat PBR materials, without replacing HDRI maps. It works on Phong and physical materials and persists in session lighting settings.

Rendering in the left panel offers Screen size, HD (1920×1080), 4K UHD (3840×2160), and 16K UHD (15360×8640). Choose the current screen, a saved camera, or all saved cameras; add jobs to the queue and start rendering. Alpha exports visible models only against a transparent PNG background, retaining their lighting while omitting backgrounds, ground/reflection/shadow floors, grids, selection and transform helpers. Normal output retains the scene environment and floor effects.

The renderer uses antialiased offscreen tiles and camera view offsets, then assembles a PNG at the requested resolution. It avoids GPU texture/viewport limits for a single huge framebuffer. Browser memory/PNG encoding still limits output: 16K needs over 500 MB for the image buffer alone. Errors appear on individual jobs and in Preferences Error logs; smaller jobs can continue. Cancellation occurs between tiles; PNG encoding already in progress finishes before cancellation takes effect. Camera, background, lights, render target, renderer state and visibility restore after success, failure or cancellation.

The queue sits below Details on the right. Minimize Details independently to keep jobs visible. Jobs run sequentially, using the current scene when the queue starts and camera snapshots taken when queued. Scene edits are locked while rendering; embedded/timeline playback pauses. Completed PNGs download only when explicitly requested. Nothing is uploaded. Jobs/images are held in the current browser tab, cleared on logout, and not persisted in sessions. Up to 20 pending jobs and 50 status entries are retained, with a 256 MiB completed-image budget; older images expire if necessary, while the newest completed PNG remains available even if it exceeds the budget. Download finished images before closing the tab.

Agent commands use the same queue as the UI: `render.open`, `render.queue.enqueue`, `inspect`, `start`, `stop`, `cancel`, `clear`, `download`, and `sidebar.details.collapse`. Start returns immediately so agents can inspect or cancel active work. `lighting.effects` supports `ambientIntensity` and six-digit `ambientColor`.

W/L/H and Scale (%) fields update live as valid values are typed. Percentage changes are relative to the dimensions at the start of that edit, avoiding compounding on every keystroke. Blur/change commits one Undo entry and refreshes calculated model details. Apply scale and the Cast + Receive explanation are removed.

The compact array dialog keeps W/L/H counts on one row. Alternate layer rotation offers None, 45°, 90° and 180°: layers 2, 4, 6… rotate around their bounding-box centers about world Y. All cells use a footprint large enough for both orientations, so rectangular models do not overlap; gaps on unrotated layers can result. Auto grouping, shared instances, cancellation/rollback and Undo/Redo remain. Decimation previews include the alternating orientation. `object.array` supports `layerRotation` with the same presets.

Floor shadows use an isolated RGBA silhouette mask projected along world lighting (including environment rotation), with caster copies for visible meshes whose Cast shadows setting is enabled. This floor-only control does not enable Three.js shadow-map samplers, change the original model alpha/materials, add a camera-following light, or create model self-shadows. Depth testing protects opaque models and the floor renders before transparent models. Skinned, morphed and instanced caster transforms are retained. A below-horizon light produces no floor shadow; GPU/capture errors clear the floor mask and restore renderer state. `lighting.shadow.inspect` reports `pipeline` and `captureError` alongside visibility/shader diagnostics.
