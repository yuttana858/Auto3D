# Auto3D 0.89.0 / Packaging 1.15.0 / Primary Products 0.15.0 / Molded Pulp 0.3.0

Opening a Parasolid file now detects its filename type and opens Convert CAD. Choosing a source in the converter starts private conversion automatically (after actual coordinate units are selected for Parasolid), then adds the ready GLB to the same scene. This removes manual saving, reopening and Add clicks. Supported appearance travels with GLB. Ordinary STEP opening still uses the existing local importer.

The host controller watches one automatic job per window independently of the dialog, with bounded polling/backoff and a 30-minute deadline. It pins the original account generation, document and scene tab, waits for editor activity to finish, then captures a fresh revision for guarded insertion. Account/session/read-only changes pause insertion. Cancel/delete, failed/expired jobs and diagnostics cannot insert a model. Parsing/rendering recheck the target and roll back a late cancellation. One Undo removes the result. Closing the browser loses the in-memory watcher; history results retain the manual guarded Add action.

Filename aliases `.xmt_txt`/`.xmt_bin` normalize to Parasolid text/binary. Source validation, immutable uploads, account ownership, quotas, native checks, attempt limits and retention are unchanged. Native Cloud 3D Studio remains 0.5.0. No database, provider credential or backend deployment change is required.

`conversion.submit` uses the shared automatic workflow and adds strict optional `autoImport` (default true; false retains manual Add). `conversion.inspect` reports the detected type and bounded workflow state/job/result. `conversion.retry` tracks its ready GLB for insertion in the current originating document; queue/attempt budgets are unchanged. Merely opening the panel, listing history or staging a file through code does not submit it. Picker selection, units choice, sample or explicit submit/retry is required.

The new tests cover real synthetic colored/alpha GLB insertion, Undo/Redo, units, aliases, account/document/tab/read-only changes, deferred rendering/cancellation rollback, duplicate polls, transient reconnect, editor activity, manual opt-out, bounded watching, strict commands and macro execution. The desktop/mobile flow covers automatic opening, units-triggered upload, panel-close completion, subsequent STEP conversion, optional download and server diagnostics without creating models from reports. All fixtures are public synthetic data; no customer CAD is downloaded into the agent workspace.

Validation and publication evidence will be recorded here after the release batch completes. See [CAD conversion](cad-conversion.md) and [commercial SDK research](cad-commercial-sdk.md).
